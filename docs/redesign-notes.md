# 墨阅 UI 重设计：思路说明

![改版前后对比](前后对比.png)

## 一、原来哪里"难绷"

1. **一个界面被切成好几块。** 目录、灰色桌面、纸张、桌面，左右各有一条空白窄带，深色主题里像断开的长条。浅色主题的灰绿底色发闷。
2. **工具栏有 12 个一样大的图标。** 常用和不常用的没分开，A−/A+ 用文字当按钮，跟图标风格不一致。
3. **同样的信息出现三遍。** 文件名在标题栏、窗口标题、状态栏各显示一次。
4. **目录序号混着用。** 一级标题用"一"，二级用"1"。大多数文档只有一个 H1 当题目，结果目录第一项永远是个孤零零的"一"。
5. **Windows 上正文会掉到宋体（SimSun）。** 17px 下笔画发虚，加粗是系统伪造的，糊成一团。这在 Windows 上大概是最影响观感的一条。
6. **几个小毛病：**
   - 首页的进度条是满的；
   - 行内代码带边框，打断了行的节奏；
   - 窗口按钮比 Windows 原生的小，也没贴着边。

## 二、核心概念：一张纸，一方印

整个窗口就是一张纸。标题栏、目录、正文用同一个底色，只靠留白和 1px 细线分区，不再有"桌面"。

颜色取自国画颜料，每种只做一件事：

| 颜料 | 用途 | 浅色 | 深色 |
|---|---|---|---|
| 墨 | 文字 | #1c1f25 | #d8dbe0 |
| 花青 | 链接、选中状态、焦点、阅读进度 | #2d4e8c | #93abdd |
| 朱砂 | 只用在印章（图标）和错误提示 | #b5372a | 印章 #c4493a，文字 #e06a57 |
| 藤黄 | 只用于查找高亮和 `<mark>` | 半透明 | 半透明 |

整个界面只有印章这一块是饱和色。纸色是 #fafaf8（浅色）和 #1b1d22（深色），故意不用米黄，避开"奶油纸 + 赭红"那种烂大街的配色。

对比度都按 WCAG AA 检查过：

- 正文：浅色 15.8:1，深色 12.2:1
- 次要文字：浅色 7.8:1，深色 7.0:1
- 最淡的提示文字：浅色 4.8:1，深色 5.1:1
- 链接：浅色 7.8:1，深色 7.3:1
- 深色主题里的错误文字：5.1:1

## 三、字体：按中文书刊的老规矩

- **标题一律用黑体**（微软雅黑）。它有真正的粗体，不会伪粗。
- **正文可以选黑体或宋体**，在"阅读设置"里切换，设置会保存。
  - 默认用黑体，因为每台 Windows 都有、都好看。
  - 宋体会优先找思源宋体 / Noto Serif，找不到才退回 Georgia 加系统宋体。装了思源宋体，宋体模式的效果会好很多。
  - 宋体模式下，**加粗的字换成黑体**。这是中文排版"宋体正文、黑体强调"的惯例，同时也避开了宋体伪粗。
- **引用块用楷体**，这是中文书里引文的传统排法。西文部分配 Georgia。
- **界面文字用系统字体**（Segoe UI + 微软雅黑 UI），和 Windows 自带程序一个味道。
- 开启 `text-autospace`：新版 WebView2 会自动在中西文之间留一点空隙，旧版会直接忽略这个设置。

正文最宽 36em（17px 下一行大约 36 个汉字），黑体行高 1.8，宋体 1.9。

## 四、布局

```
┌─[印] 墨阅使用说明.md ▾ › 安装与启动 ────── 目录 查找 译 Aa ⋯ │ — ▢ ✕ ┐
├══════════════ 花青进度 ═══════════════────────────────────────────────┤
│ 目录                │                                                 │
│ 墨阅使用说明（题目）│        # 墨阅使用说明                           │
│ ┃安装与启动         │        正文……                                   │
│    快捷键一览       │                                                 │
│ 写作约定            │                                                 │
└─────────────────────┴─────────────────────────────────────────────────┘
```

**1. 标题栏里的"书眉"（这次改版最有特色的地方）。** 文件名后面实时显示你正在读的那一节，就像书页顶上印的章名。滚到新的一节时，节名会淡出再淡入。点文件名会弹出一个面板，里面有：

- 路径、编码、字数、行数、阅读时间
- 最近打开的文件
- "打开其他文件"

原来的状态栏因此删掉了，正文多出一行高度。

**2. 工具栏从 12 个减到 5 个。** 目录、查找、翻译、Aa、⋯。

- Aa 是"阅读设置"，合并了字号、正文字体、深浅色。
- ⋯ 里放打开、重新读取、导出、打印、快捷键，每一项右边都标着快捷键。
- 首页只显示 Aa 和 ⋯。

**3. 窗口按钮做成 Windows 原生规格。** 46px 宽、占满标题栏高度、贴紧右上角，关闭按钮悬停时变成系统红 #c42b1c。

**4. 阅读进度就是标题栏的下边线。** 1px 灰线上叠一条 2px 的花青线。首页不显示进度。

**5. 目录不再编号。** 层级靠缩进表示。如果文档只有一个 H1 而且排在最前面，就把它当题目：加粗显示，其余标题按相对层级缩进。当前所在的节用花青色加左侧短竖线标出。判断"当前节"改成按滚动位置二分查找，往回滚也能正确更新。

## 五、细节

- **行内代码**：去掉边框，只留浅底色。
- **代码块**：取消顶部那一条标题栏。语言名淡淡地挂在右上角，鼠标悬停时同一位置换成"复制"按钮。没写语言的代码块不再显示 "text"。
- **表格**：三线表（上粗、下粗、表头下细）。
- **分隔线**：做成书里"换场"用的居中短线，不再是整行横线。
- **任务列表**：复选框改成自绘样式，选中时是花青底加白勾，不再是系统那种灰蒙蒙的禁用样式。
- **查找**：改成浮在正文右上角的小框，不遮住正文开头。没有结果时计数变成朱砂色。打开查找时会自动带上选中的文字。
- **提示消息**：放在底部居中，深浅颜色和当前主题反过来，用小圆点区分成功和出错，最多同时显示 3 条。
- **首页**：
  - 左对齐的单栏：大印章、标题、一句说明。
  - "打开文件"按钮旁边标出 Ctrl O。
  - 下面是最近文件：文件名一行，目录一行。路径太长时从左边省略，保留最有用的最后几级目录。
- **拖放**：整个窗口蒙上一层淡色，四周画一圈花青虚线框，中间写"松手打开"。
- **窄窗口**：目录宽度缩到 200px，标题栏里的节名隐藏，版心两侧的边距缩小。
- **键盘**：下拉菜单可以用方向键选择，按 Esc 时焦点回到打开菜单的那个按钮，所有按钮都有焦点框。
- **减少动效**：系统开启"减少动画"时，所有过渡和动画都关掉。

## 七、顺手修掉的 bug

- 首页的进度条是满的。
- 往上滚动时，目录高亮不会切回上一节。
- 全文翻译之后切换语言没有反应（原来记录的原文是空字符串，切换时直接返回了）。
- 右键"翻译这段"时，点击菜单可能把选中的文字清掉，导致没东西可翻译。
- 代码块里的 `code` 被行内代码样式盖住，多出一层底色和内边距（`:is(#doc)` 的 ID 优先级比 `.codebox pre code` 高）。

## 八、还没验证的地方

- **Rust 部分没编译过。** 改动是照着现有 `show_toc` 的写法照抄的，请本地 `cargo build` 一下。
- **截图不是在 Windows 上拍的。** 测试环境没有微软雅黑、楷体、Segoe、Consolas，所以截图里中文是 Noto 字体，引用块也不是楷体。实机效果以 WebView2 为准。
- **`text-autospace` 要看 WebView2 的版本**，旧版会忽略这个设置，不影响其他效果。

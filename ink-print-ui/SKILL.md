# 印本风界面（Ink & Print）

一句话：**整个窗口是一张纸，只有印章是饱和色；结构靠留白和 1px 细线表达，不用阴影和卡片；字是主角。**

## 什么时候用

- 阅读密集界面：文档查看器、Markdown/PDF 阅读器、笔记、知识库、文档站。
- 工具型界面也可以：编辑器、终端、监控面板、配置台——只要信息本身是主角。
- 判断标准：用户会在这里**停留很久**看内容，而不是被引导着点按钮。

不要用在：需要情绪冲击的落地页、儿童/娱乐向产品、纯游戏 HUD，或用户已经给了别的视觉方向时（用户的方向永远优先）。

## 先想清楚四件事

动手前先定：**主题**（这个产品在什么世界里）、**读者**（谁在用、什么场景）、**主要任务**（一眼看过去要完成什么）、**押注点**（只允许一处大胆）。

对阅读类界面，主要任务几乎总是"让眼睛舒服地把内容读完"，押注点应该花在**正文排版**上（字体、度量、留白），而不是装饰。

> 这一节的思路来自 Anthropic 的 frontend-design skill（MIT）：以主题为根、避免"AI 默认脸"、只在一处大胆、出门前摘掉一件配饰。下面是它在这个画风里的具体落法。

## 签名（缺一条就不成立）

1. **一张纸。** 标题栏、目录、正文、面板**同一个底色**（浅 `#fafaf8` / 深 `#1b1d22`），只用留白和 1px 细线分区。**绝不要引入第二种"外壳色"**——一旦有"桌面 + 卡片"，界面立刻变成被切成好几块。纸色不要米黄（那是"奶油纸 + 赭红"的烂大街配色），也不要纯白纯黑。
2. **四种颜料，各干一件事。** 墨写字，花青（`#2d4e8c` / `#93abdd`）管链接、选中、焦点、进度，朱砂（`#b5372a` / `#c4493a`）**只给印章**（错误提示可以用它的浅色版本），藤黄只给查找命中与 `<mark>`。**整个界面只有印章一个饱和色**；强调色超过三种就不叫强调了。
3. **留白与细线代替阴影和卡片。** 分区用 1px `--rule` 界行，层级用 `--paper-2/3` 的深浅一档。柔和投影只允许出现在"真的浮起来"的东西上（查找框、浮层）。
4. **直角为骨。** 圆角 3px，只给需要按下的东西；印章 6px、浮层 8px。表格、代码块、面板一律直角。
5. **字体按中文书刊的老规矩。** 标题一律黑体（`--sans`，微软雅黑有真粗体）；正文可在黑体/宋体间切换（黑体 1.8 行高、宋体 1.9）；**宋体模式下加粗的字换成黑体**——既符合"宋体正文、黑体强调"的传统，也避开宋体的伪粗；引文用楷体。界面文字用系统字体。
6. **版心收窄。** 正文 36em（17px 下约 36 个汉字，拉丁 ≤ 80 字符），行高 ≥ 1.8，段落间距约 .9em。
7. **动效是回应，不是装饰。** 140–260ms、`cubic-bezier(.22,.8,.3,1)`，只在用户动作后发生。**唯一的例外是启动**：纸面浮起 + 印章落印，两条非线性缓动、总长 ~0.5s、跑一次。

完整色值、字体栈、字号/间距/动效 token 见 [references/tokens.md](references/tokens.md)，可直接粘贴的 CSS 在 [assets/ink-print-tokens.css](assets/ink-print-tokens.css)。

## 布局

```
┌─[印] 文件名 ⌄ › 当前小节 ────────────── 目录 查找 译 Aa ⋯ │ — ▢ ✕ ┐  标题栏 = 工具栏
├═════════════ 花青进度（就是标题栏的下边线）═════════════════════════┤
│ 目录                │                                               │
│  文档题名（加粗）   │        # 标题                                 │
│ ┃当前章节           │        正文……                                 │
└─────────────────────┴───────────────────────────────────────────────┘
```

- **书眉**：标题栏左边显示"文件名 + 正在读的那一节"，像书页顶上印的章名；切小节时淡出淡入。点文件名弹出面板（路径、编码、字数、行数、阅读时间、最近打开、打开其他文件）——所以**底部状态栏可以整个删掉**，正文多一行高度。
- **工具栏只放常用的 5 个**（目录 / 查找 / 翻译 / 阅读设置 Aa / 更多 ⋯），其余进 ⋯ 菜单并**在右边标出快捷键**。字号、正文字体、深浅色合并进 Aa 面板。没有文档时只留 Aa 和 ⋯。
- **目录不编号**：靠缩进表示层级；文档开头的单个 H1 当题目（加粗），当前节用花青竖线 + 花青文字；"当前节"按滚动位置二分查找，往回滚也要正确。
- **表格是三线表**：表头上下 1.5px、行间 1px，没有竖线、没有斑马纹。
- **代码块不要标题栏**：语言名挂在右上角，悬停时同一位置换成"复制"；正文等宽 + 软换行（`white-space: break-spaces`），长路径在 `/` 后插 `<wbr>` 断点；没标语言的块不上色、不显示标签。
- **查找框浮在正文右上角**（不要占满一整条横栏），无结果时计数变朱砂色。
- **提示条在底部居中**，颜色与当前主题相反。
- **侧栏面板参与布局**（正文跟着变窄，不是被盖住）；打开侧栏时先收起目录。

组件配方（含可复制的 CSS/JS）见 [references/patterns.md](references/patterns.md)。

## 文案

字和颜色一样是设计材料。写之前先问：这一句帮用户理解或行动了吗？

- 用动词开头说清"点了会发生什么"（`导出网页`），不要 `提交`。
- 同一个动作在按钮、提示、结果里用同一个词。
- 错误说清**发生了什么 + 怎么修**，不道歉、不卖萌、不含糊。
- 空状态是邀请，不是宣传："把 Markdown 文件拖进窗口，或者从电脑里选一个。"
- 不要全大写 eyebrow 小标签、不要 `词 — 片段` 式标签、不要给每段配图标。

## 别做（这些是"AI 默认脸"）

- 近黑底 + 单一荧光/朱红强调色（AI 味最重的一条）
- 全套同一个圆角 + 同一种灰色柔和投影的卡片堆
- 外壳色 + 卡片色两层结构（"桌面 + 纸"也不行，这个画风是一张纸）
- 每个区块都配 eyebrow 小标签 / 编号 / 图标
- 拿渐变当装饰、拿等宽字体当小标签
- 变成仿古：纸纹贴图、滥贴印章、花边框、首字下沉、毛笔字标题——**这是"印本的排版逻辑"，不是"古风皮肤"**
- 一个界面里强调色超过三种

## 流程

1. **先写一页纸的 plan**：4–6 个具名色值（写 hex 和用途）、字体与各自角色、布局概念（ASCII 线框图，含对齐方式）、三条原则。
2. **对照"别做"逐条自查**：命中哪条就改掉，并说清改了什么、为什么。
3. **再写代码。** 注意选择器特异性：`.section` 和元素选择器互相抵消 padding/margin 的问题最容易在这里翻车。
4. **截图自评。** 一张截图胜过一千 token：深色、浅色、窄窗口各看一遍。
5. **出门前摘掉一件配饰。** 删掉一个不服务于内容的装饰——通常是第一个想加的动效或那条多余的强调色。

## 交付前检查

- [ ] 全窗口只有一个底色，分区靠留白和 1px 细线（没有第二种"外壳色"）
- [ ] 只有印章是饱和色；花青/朱砂/藤黄各只干一件事
- [ ] 标题是黑体（真粗体）；宋体模式下加粗换黑体；引文楷体
- [ ] 正文 measure 36em 左右，行高 ≥ 1.8
- [ ] 柔和投影只出现在真正浮起的浮层上
- [ ] 深色和浅色都是独立调过的，不是简单反色；深色下错误色要单独提亮
- [ ] 键盘焦点可见（2px 实线 outline，`outline-offset: 1px`）；菜单能用方向键选，Esc 后焦点回到触发按钮
- [ ] `prefers-reduced-motion: reduce` 下动效与平滑滚动全部关闭
- [ ] 启动动效只跑一次，且不影响首屏可读（首帧就要能看清内容）
- [ ] 打印样式：隐藏 chrome，正文黑字白底
- [ ] 没有横向滚动条；宽表格、长路径、长 URL 都能收进版心
- [ ] 正文对比度 ≥ 7:1，次要文字 ≥ 4.5:1
